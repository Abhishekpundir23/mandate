# Improvement Changelog

This is the labelled improvement changelog for MANDATE. The baseline is the repository state before the first runnable implementation, and each later row groups commits that pursued one coherent product or safety objective. Commit IDs are the source-history evidence; the checked-in tests and later tracked task reports preserve the corresponding RED/GREEN behavior, review findings, metrics, and verification results.

The **Standard** benchmark lane is not the development baseline. It is the final fixture-bypass control that runs the same proposal programs without MANDATE's authority gate. The development baseline below is commit `31ec577`, when only the locked specification, plan, and visual concepts existed.

## Main failure mode

The primary failure mode is **authority drift between conversation and execution**. A coding agent can keep following an earlier goal, infer permission from a plan, or treat a plausible completion statement as evidence even after the user's latest instruction narrows authority. In the benchmark's fixture-bypass control, that class of behavior produces 8 unauthorized effects and 3 false completion claims; in the flagship flow, Standard submits while MANDATE blocks the same proposal and preserves the draft.

MANDATE addresses this at the causal boundary: compile ordered user intent into versioned authority, bind the current version to the exact proposed action fingerprint, execute only after an `ALLOW`, and accept completion claims only when prior replay-valid observations and terminal-world predicates support them. A later explanation cannot undo an already executed side effect.

## Hot take

**A plan is not permission, memory is not authority, and fluent prose is not evidence.** The more capable a coding agent becomes, the less acceptable it is to leave authorization as an informal prompt-reading convention. Agent products should make authority a versioned runtime primitive, gate effects where they occur, and grade outcomes from observations—not from the agent's confidence.

This claim is intentionally bounded. MANDATE demonstrates the approach over its current deterministic 15-scenario catalog and the production subset covered by its closed-world analyzer; it does not claim a proof over arbitrary JavaScript, arbitrary third-party behavior, or every real-world workflow.
